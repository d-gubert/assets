Life of a Token.

Follow one chat request through a small Llama-style transformer that runs in this page. The tokenizer, the four blocks, the sampler, and the stop check all run live, so every number on the page comes from the model.

What is real here

The model is a real transformer with 296,256 parameters. It trained for about a minute on a laptop CPU, on 60,000 short chat transcripts about 16 animals. It knows those facts and little else, so other questions give confident nonsense.

What a real server does differently

A real server runs a model about 27,000 times larger on GPUs, with many requests in one batch, a paged KV cache, and fused kernels. This page runs one request in plain JavaScript. It feeds the prompt one position at a time, which gives the same numbers as one parallel prefill pass.

Source

The page, the engine, and the training script are in the simulation/ folder of the research repository. Its README explains how to rebuild the model.
