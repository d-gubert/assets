Reference

Glossary

The canonical vocabulary for this workspace. A term is only added here once you have used it correctly — so this file is a record of what you know, not a list of what you should read.

The cursor

Cursor
An input string paired with a position into it. The complete state of a hand-written parser. Avoid: pointer, iterator, reader
Position
The index of the next character that has not yet been consumed. Monotonic — it only ever moves forward, except during deliberate backtracking. Avoid: offset, index, cursor (the cursor is the whole thing)
Peek
Reading the character at the position without moving it. The operation used to decide. Avoid: lookahead (that word is reserved for a different, larger idea)
Advance
Reading the character at the position and moving past it. The operation used to commit. Avoid: next, read, eat, bump
Consume
To advance past one or more characters, having decided what they are. Consumed characters are behind the position and will not be seen again.
Sentinel
A value returned in place of a real character when the position is past the end of input — "\0" in this workspace. It exists so loop conditions terminate without a bounds check at every call site. Avoid: null character, EOF marker
Character class
A predicate over a single character, written as range comparisons — isDigit, isAlpha, isHex.

Formats

Field
One meaningful value inside a formatted string — a width, a name, a pane id.
Delimiter
A character whose job is to separate fields. Splitting on a delimiter is only valid when no field may contain it.

Terms arriving in later lessons — lexeme, token, tokenizer, grammar, terminal, non-terminal, recursive descent, lookahead, backtracking, ambiguity, EBNF — are deliberately not listed yet. They go in once used, not once mentioned.
