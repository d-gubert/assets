    Every permission an App can ask for, named so that the manifest never has to spell one out as a string.

    App Permission naming rules:

    'scope-name': { 'permission-name': { name: 'scope-name.permission-name' } }

    You can retrieve this permission by using: AppPermissions['scope-name']['permission-name'] -> { name: 'scope-name.permission-name' }
